Sobre o Projeto

Introdução

Este projeto foi desenvolvido para comparar, de forma cega, o desempenho de duas abordagens de LLM (Large Language Models, em português, Grandes Modelos de Linguagem) aplicadas ao domínio das contratações públicas no Brasil. Detalhes sobre os modelos foram suprimidos intencionalmente. A pesquisa investiga se a diferença entre as duas abordagens também afeta a preferência pelas respostas geradas para diferentes níveis de conhecimento sobre o assunto.

Metodologia

Os participantes interagem com a aplicação via chat, enviando perguntas relacionadas às contratações públicas. Cada sessão apresenta dois painéis de chat (Chat A e Chat B), nos quais os modelos (X e Y) são alocados aleatoriamente a cada nova conversa. A qualquer momento, os usuários podem avaliar a qualidade da interação por meio de botões e fornecer informações opcionais (nome, email e nível de proficiência). Os dados coletados são armazenados e posteriormente analisados utilizando métodos para determinar se existe uma vantagem significativa em utilizar um modelo em detrimento do outro.

Resultados

Abaixo está uma breve explicação das análises apresentadas na página de resultados:

  • Tabela de Avaliações: Mostra a contagem de vitórias de cada modelo (Modelo X e Modelo Y) agrupada por nível de proficiência dos participantes. A coluna "Y/X" indica a razão entre as vitórias do Modelo Y e do Modelo X, sendo importante porque revela se um modelo é consistentemente preferido em relação ao outro em cada grupo, destacando a vantagem relativa de desempenho.
  • Análises Estatísticas: Apresenta testes para verificar se a preferência por um modelo é significativamente diferente de 50%, com as seguintes colunas:
    • Proporção Amostral p-hat: Representa a porcentagem de vezes que o Modelo Y foi preferido, oferecendo uma estimativa inicial da preferência dos usuários.
    • Valor-p: Mostra a probabilidade de que a diferença observada ocorra por acaso. Um valor menor que 0,05 indica que a preferência é estatisticamente significativa.
    • Margem de Erro: Indica a variação esperada na proporção estimada, baseada em um nível de confiança de 95%, ajudando a avaliar a precisão dos resultados.
    • Intervalo de Confiança: Define a faixa onde a verdadeira proporção de preferência pelo Modelo Y deve estar, com 95% de confiança, oferecendo uma visão robusta da tendência.
    • Significativo?: Responde "Sim" ou "Não" com base no valor-p, resumindo se a preferência por um modelo é estatisticamente relevante.
    Esses dados são essenciais para determinar se a preferência por um modelo é real ou apenas uma flutuação aleatória.
  • 20 Últimas Avaliações: Lista as 20 avaliações mais recentes, com data/hora, modelo vencedor e nível de proficiência do participante. É importante porque permite identificar padrões ou tendências recentes nas preferências dos usuários, oferecendo uma visão atualizada das escolhas.
